# Datamarcos

Live, mentor-led AI and data engineering training for students and working professionals.

We teach people how to scope, build, evaluate, secure and deploy AI systems in real environments. Our four flagship programmes cover Forward Deployed AI Engineering, Generative AI and Agentic AI, Applied Agentic AI, and Advance Data Engineering with applied GenAI. Datamarcos has trained 25,000+ learners across 200+ organizations in 10+ countries, drawing on 18+ years of practice.

This GitHub organisation is for **free learning material**. You do not need to join a programme to use it.

## Repositories

- [fde-roadmap](https://github.com/datamarcos-official/fde-roadmap) — a self-study roadmap for forward deployed AI engineers, with a week-by-week plan and a reading list of primary sources.
- [agentic-ai-projects](https://github.com/datamarcos-official/agentic-ai-projects) — beginner-to-advanced project ideas, including a small offline RAG example you can run with the Python standard library.
